API pública

Efemérides Cristianas

Consulta acontecimientos históricos por fecha o año y accede a sus imágenes mediante una API HTTP sencilla con respuestas JSON.

Formato JSON
Autenticación No requerida
Ruta base /api/efemerides
Referencia

Endpoints

Los parámetros :mes y :dia admiten valores con o sin cero inicial.

GET /api/efemerides/hoy

Devuelve todas las efemérides correspondientes al día y mes actuales, independientemente del año histórico.

Ejemplo de URL http://localhost:3000/api/efemerides/hoy
Ejemplo de respuesta JSON 
{
  "fecha": "14-08",
  "total": 1,
  "efemerides": [
    {
      "id": 18,
      "fecha_dia": 14,
      "fecha_mes": 8,
      "fecha_anno": 1552,
      "titulo": "Acontecimiento histórico",
      "resumen": "Descripción de la efeméride.",
      "imagen_url": "/api/efemerides/18/imagen"
    }
  ]
}
GET /api/efemerides/:mes/:dia

Consulta todas las efemérides de un día y mes concretos, sin filtrar por año.

Ejemplo de URL http://localhost:3000/api/efemerides/08/12
Ejemplo de respuesta JSON 
{
  "fecha": "12-08",
  "total": 2,
  "efemerides": [
    { "id": 7, "fecha_dia": 12, "fecha_mes": 8, "fecha_anno": 1515, "titulo": "Primera efeméride", "resumen": "...", "imagen_url": "/api/efemerides/7/imagen" },
    { "id": 9, "fecha_dia": 12, "fecha_mes": 8, "fecha_anno": 1546, "titulo": "Segunda efeméride", "resumen": "...", "imagen_url": null }
  ]
}
GET /api/efemerides/anno/:anno

Devuelve todas las efemérides registradas para un año histórico concreto, ordenadas por mes y día.

Ejemplo de URL http://localhost:3000/api/efemerides/anno/1515
Ejemplo de respuesta JSON 
{
  "anno": 1515,
  "total": 1,
  "efemerides": [
    { "id": 7, "fecha_dia": 12, "fecha_mes": 8, "fecha_anno": 1515, "titulo": "Acontecimiento de 1515", "resumen": "...", "imagen_url": "/api/efemerides/7/imagen" }
  ]
}
GET /api/efemerides/:mes/:dia/:anno

Filtra simultáneamente por mes, día y año para obtener únicamente las coincidencias de una fecha histórica específica.

Ejemplo de URL http://localhost:3000/api/efemerides/08/12/1515
Ejemplo de respuesta JSON 
{
  "fecha": "12-08-1515",
  "total": 1,
  "efemerides": [
    {
      "id": 7,
      "fecha_dia": 12,
      "fecha_mes": 8,
      "fecha_anno": 1515,
      "titulo": "Acontecimiento de 1515",
      "resumen": "Descripción completa.",
      "imagen_url": "/api/efemerides/7/imagen",
      "creado_en": "2026-08-14T12:00:00.000Z",
      "actualizado_en": "2026-08-14T12:00:00.000Z"
    }
  ]
}
GET /api/efemerides/:id/imagen

Devuelve el archivo WebP almacenado para una efeméride. Responde con image/webp, no con JSON.

Ejemplo de URL http://localhost:3000/api/efemerides/7/imagen
Ejemplo de respuesta 
HTTP/1.1 200 OK
Content-Type: image/webp
Cache-Control: public, max-age=86400

[contenido binario de la imagen]
GET /api/efemerides

Listado general con filtros opcionales por mes, dia, anno y limite.

Ejemplo de URL http://localhost:3000/api/efemerides?mes=8&dia=12&limite=10
Ejemplo de respuesta JSON 
{
  "total": 2,
  "efemerides": [
    { "id": 7, "fecha_dia": 12, "fecha_mes": 8, "fecha_anno": 1515, "titulo": "Primera efeméride", "resumen": "...", "imagen_url": "/api/efemerides/7/imagen" }
  ]
}
Esquema

Campos principales

CampoDescripción
idIdentificador único de la efeméride.
fecha_diaDía del mes, entre 1 y 31.
fecha_mesMes, entre 1 y 12.
fecha_annoAño histórico; puede ser null si no está definido.
tituloNombre breve del acontecimiento.
resumenDescripción completa de la efeméride.
imagen_urlRuta pública de la imagen WebP o null si no existe.
creado_enFecha ISO 8601 de creación del registro.
actualizado_enFecha ISO 8601 de la última modificación.
